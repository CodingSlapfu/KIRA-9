# Bounded consonant cue experiment

Motivation: one listener identified original pea as bee at MIDI48/60/72 and frequently confused see/she. English6 did not improve overall identification. This is a NEW original baseline adapter, not another formant/gain/smoothing pass or English6 retune.

Hypothesis: preserve /p/ aspiration beyond the scheduled consonant boundary and route /s,sh/ noise independently of the shared resonators. /b/ gets weak prevoicing and no long aspiration. Two bounded one-pole filters; fixed control constants; no recordings or outside DSP code. Keep baseline vowels, score format and product code untouched. This trial covers P/B/IY carry only, not arbitrary consonant-vowel coverage.

Predeclared gates before execution: raw peak <.90 at velocity127 for seven voices and MIDI48/60/72/84, no nonfinite values, no output limiter hits, and STOP decays below 1e-5; /s/ spectral centroid exceeds /sh/ by >=1500Hz at each tested register; measure aspiration/periodicity from rendered PCM, rather than calling programmed timing a perceptual result. Reuse frozen baseline PCM; render candidate only on the matched corpus. Host cost <=1.25x baseline median on interleaved matching callback measurements is a provisional budget, not FM-1 evidence. Kernel-only R3 object and state size required. No ASR replay unless these technical gates improve. No integration without NEW blinded human evidence of better consonant identification, non-regressing vowels, free-text phrase understanding and naturalness, plus physical timing/headroom acceptance.

Independent reference: Lisker & Abramson, Stop Categorization and Voice Onset Time, original paper: https://www.coli.uni-saarland.de/groups/FK/speech_science/icphs/ICPhS1964/p5.1_389.pdf . Voice onset relative to release motivates testing a carried cue; 55ms here is an original test choice, not a copied synthesis implementation or universally correct English timing. Exact amplitudes/poles are our original hypotheses. No claim of human improvement from spectral separation alone.
