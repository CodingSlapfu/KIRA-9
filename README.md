# KIRA-9
**Original cybernetic English singing instrument for M-VAVE FM-1**  
**Planning package — not an implemented firmware, website, or release.**

KIRA-9 is the user's orange M-VAVE FM-1 vocalist: an expressive animated cyborg woman that sings original English lyrics as a full standalone instrument or synchronizes with AQUORA and other standards-compliant MIDI hosts. It features a companion song-writing/editor website with factory demos, lyric generation, custom lyric imports, musical/phoneme editing, a large backup library and a verified browser installer.

**Only active projects:** KIRA-9 and AQUORA. KIRA-9 is independent and must get its own GitHub repository, website, releases and issue tracker. Retired projects must not be resumed.
