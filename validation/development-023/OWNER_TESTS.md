# Physical FM-1 acceptance — v0.2.3-dev

1. Export a complete device backup while still on v0.2.2. Keep the corresponding backup and exact rollback image. Use Chrome/Edge, a data USB cable and stable device power. Install only from the labeled development installer; verify identity FM-1_74000203 and matching package build/hash receipt. Do not interrupt a flash write.
2. Listen to the same factory song before and after at the same level. Compare note attacks, connected vowels, sustain, breath, vibrato and endings in Pop/House/IDM/Trip-hop/Ethereal/Soul. Judge beauty, character and English pronunciation yourself; technical passes do not imply human acceptance. Five-grain experiment remains unpromoted.
3. Inspect the actual 240x240 character: refined proportions, skin/shadows, eye and mouth alignment, blink/gaze/emotion, closed Hum and B/P/M closures, subtle moving temple/neck parts. Check fast phrase transitions and low/high notes. The site includes genuine C-renderer before/after images and five-mode animation.
4. Try Lyrics, Vocalise, Scat, Hum and Vocables with factory songs, live keyboard and saved phrase banks. Change modes/voices mid-session; STOP/panic and pedal release must silence the instrument without stuck notes. SAVE/reboot/restore a custom song and preset. Confirm old projects remain unchanged.
5. With a generic BLE MIDI peer, pair, follow 24-PPQN clock, START/STOP/CONTINUE, notes/velocity and sustain; change tempo, disconnect/reconnect and test again. Confirm one clock master, clean recovery and no stuck notes. Wireless MIDI is preferred; wired MIDI is not an acceptance prerequisite.
6. Run at least 30 minutes while changing controls/expressions. Report audible glitches, display/control lag, CPU or resource warnings and pairing jitter. Host timing is not physical device timing.
7. If reverting, use the preserved exact v0.2.2 rollback installer. All storage/preference formats are unchanged from v0.2.2/0.2.1. Older v0.2.0/legacy images need their matching pre-update backup for newer preferences. Interrupted update/recovery and restore are physical acceptance items; no simulated test is represented as a real power-cut test.

Report mode/style/song, connected peer, firmware build, what happened and whether STOP recovered. Visual quality, naturalness/intelligibility, physical BLE, CPU/audio and flash/rollback acceptance remain OPEN. Development firmware is not an official production release.
